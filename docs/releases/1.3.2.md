# BluviBoard 1.3.2

## Настройки инструментов

- Чекбокс «Всегда показывать настройки» закрепляет панель текущего инструмента: она остаётся открытой во время рисования.
- При переключении инструментов кликом или хоткеем закреплённая панель показывает настройки выбранного инструмента.
- Выбор сохраняется на сервере для всех досок пользователя, включая новые, и восстанавливается после повторного входа. По умолчанию закрепление выключено.

## Что нового

- Убрана лишняя подпись в шапке окна «Что нового».
