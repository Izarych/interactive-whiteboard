# BluviBoard 1.6.0

## Самостоятельная доска для Windows

- Windows-приложение 0.3.0 запускается без сайта и интернета, даже при первом открытии.
- Доски, рисунки, изображения и настройки сохраняются на компьютере.
- Добавлены файлы `.bluviboard` для переноса досок и резервных копий вместе с изображениями. Импорт создаёт новую доску, не заменяя существующие.

## Синхронизация аккаунта

- Войдите в Windows-приложении, чтобы загружать доски аккаунта и отправлять локальные изменения при подключении.
- Перенос досок устройства в аккаунт включается отдельной галочкой при входе.
- При конфликте с изменениями на сайте сохраняются обе версии. Открытый холст не заменяется в фоне.
- Повторная отправка после обрыва связи не создаёт дубликаты досок.

Для автономной работы обновите Windows-приложение до **0.3.0**. Браузерная версия остаётся онлайн-доской. Совместное рисование и управление ссылками доступны на сайте; оффлайн-изменения совместной доски сохраняются отдельной копией.
