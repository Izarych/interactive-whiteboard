# BluviBoard 1.3.0

## Рисование

- Полупрозрачный маркер для выделения рукописных линий и изображений. Цвет, толщину и непрозрачность можно настроить.
- Выделение маркером сохраняется на доске, поддерживает отмену, повтор, стирание и экспорт PNG.
- Клик по инструменту сразу открывает его настройки под панелью. Хоткеи переключают инструменты без открытия настроек.

## Плавность штрихов

- При рисовании учитываются промежуточные точки движения мыши и пера, объединённые браузером в одно событие.
- Текущий штрих рисуется отдельно от сохранённого содержимого, снижая нагрузку на заполненных досках.

## Что нового

- После обновления приложение показывает окно с номером версии и описанием изменений.
- После закрытия описание можно снова открыть кнопкой «Что нового» на стартовой странице или в боковой панели.
