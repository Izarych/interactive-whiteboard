# BluviBoard для Windows 0.1.0

Первый отдельный Windows-клиент BluviBoard.

## Возможности

- Установка через `.exe`, ярлыки и удаление через настройки Windows.
- Доски в отдельном окне с сохранением входа между запусками.
- Рисование, изображения, Ctrl+V, отмена и повтор действий.
- Экспорт PNG через системный диалог сохранения.
- Ожидание сохранения доски и загрузки изображений перед закрытием окна.
- Повторное подключение при запуске без интернета.

## Установка

Скачайте **BluviBoard-Setup-0.1.0-x64.exe**, запустите установщик и следуйте его указаниям. Поддерживаются Windows 10/11 x64. Если WebView2 отсутствует, установщик загрузит его автоматически.

Для работы нужен интернет. При первом запуске войдите в аккаунт или начните как гость; вход в приложении сохраняется отдельно от браузера.

Установщик пока без цифровой подписи издателя. Windows может показывать предупреждение о неизвестном приложении.

Интерфейс обновляется с сайта. Новые версии Windows-клиента устанавливаются запуском нового установщика; вход сохраняется.
