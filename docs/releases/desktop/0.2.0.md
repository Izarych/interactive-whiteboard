# BluviBoard для Windows 0.2.0

## Рисование

- Выравнивание нарисованных линий и распознавание прямоугольников, квадратов, треугольников, кругов и эллипсов при удержании Shift.
- Живое превью выровненной фигуры и выбор модификатора Shift, Alt или Ctrl в настройках карандаша.
- Точечный ластик с настраиваемым размером, который сохраняет остальные части линии и контура.
- Shift + ластик удаляет весь исходный объект, включая его ранее разрезанные части.
- Отмена, повтор и сохранение частично стёртых рисунков.

## Обновления

- Автоматическая проверка Windows-обновлений при запуске.
- Кнопка **«Проверить обновления»** на экране входа и в боковой панели.
- Отображение установленной и доступной версий, ссылка на новый установщик.
- Сохранение текущей доски перед скачиванием обновления.

## Установка

Скачайте **BluviBoard-Setup-0.2.0-x64.exe**, закройте приложение и запустите установщик. Вход сохраняется при обновлении. Поддерживаются Windows 10/11 x64; для работы нужен интернет.

Установщик пока без цифровой подписи издателя.
