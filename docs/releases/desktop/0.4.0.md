# BluviBoard для Windows и macOS 0.4.0

## Windows и macOS

- Один автономный редактор для Windows 10/11 x64 и macOS 14+.
- Для Mac с Apple Silicon скачайте `BluviBoard-0.4.0-macOS-arm64.dmg`; для Intel — `BluviBoard-0.4.0-macOS-x64.dmg`. Откройте образ и перетащите BluviBoard в «Программы».
- Для Windows используйте `BluviBoard-Setup-0.4.0-x64.exe`.
- Рисование, изображения, локальное сохранение, экспорт PNG и файлы `.bluviboard` работают без сайта и интернета.
- Исправлено чтение сохранённых изображений в WebKit, чтобы экспорт и синхронизация не зависели от временного файла загрузки.
- На Mac добавлены команды меню, копирование/вставка и безопасное завершение через Cmd+Q. Ошибка записи оставляет возможность повторить сохранение.

## Синхронизация и обновления

- Для обмена досками с сайтом войдите в аккаунт при наличии интернета. Пароль не сохраняется, сессия хранится в Windows Credential Manager или macOS Keychain.
- Локальные доски устройства переносятся в аккаунт только с вашего согласия. При конфликте сохраняются обе версии.
- «Проверить обновления» выбирает файл под установленную систему и архитектуру, а не предлагает Windows-файл пользователям Mac.
- Совместное рисование и управление ссылками остаются на сайте. Оффлайн-редактирование совместной доски создаёт отдельную копию.

## Перед установкой

Данные Windows 0.3.0 сохраняются при обновлении. Перед переходом с 0.2.0 подключите старую программу к интернету и дождитесь сохранения досок: неотправленные черновики её сетевого профиля не импортируются автоматически. Для переноса между компьютерами или из Offline Preview используйте файлы `.bluviboard`.

Установщики пока без подписи издателя; Mac-сборки не нотариализованы Apple. При первом запуске система может показать предупреждение безопасности.
