# BluviBoard для Windows 0.3.0

## Работа без интернета

- Редактор встроен в программу: запуск, создание досок, рисование и изображения работают без сайта, аккаунта и предварительного подключения.
- Документы, изображения и настройки сохраняются на компьютере. Закрытие ждёт окончания штриха и записи; при ошибке сохранения можно повторить попытку.
- Сохранены инструменты рисования, хоткеи и закрепление панели настроек.
- Добавлены экспорт и импорт `.bluviboard`: файл содержит доску и изображения, но не учётные данные. Импорт создаёт новую доску. Экспорт PNG также работает оффлайн.

## Синхронизация с аккаунтом

- Входите при наличии интернета, затем продолжайте работать локально. При восстановлении подключения изменения отправляются автоматически.
- Доски устройства отправляются в аккаунт только с вашего согласия при входе. Кэши разных аккаунтов разделены.
- При конфликте с сайтом сохраняются обе версии отдельными досками; текущий холст не подменяется в фоне.
- Пароль не сохраняется, сессия хранится в защищённом хранилище Windows.
- Совместное рисование и ссылки остаются на сайте. Оффлайн-редактирование совместной доски создаёт отдельную облачную копию.

## Установка и переход с 0.2.0

Скачайте **BluviBoard-Setup-0.3.0-x64.exe**, закройте приложение и запустите установщик. Поддерживаются Windows 10/11 x64. Среда WebView2 включена в установщик, поэтому он заметно больше и не требует её скачивания при установке без интернета.

**Перед обновлением подключите прежнюю программу к интернету и дождитесь сохранения всех досок.** Неотправленные черновики старой версии не переносятся автоматически. Существующие данные старого профиля не удаляются. После обновления войдите заново для синхронизации досок аккаунта; без входа откроется отдельное локальное пространство.

Offline Preview остаётся отдельной программой. Для переноса его локальных досок используйте файлы `.bluviboard`.

Новые версии можно проверить кнопкой «Проверить обновления» при наличии интернета. Для локального запуска проверка обновлений не требуется. Установщик пока без цифровой подписи издателя.
