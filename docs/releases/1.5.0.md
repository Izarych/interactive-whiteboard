# BluviBoard 1.5.0

## Совместные доски по ссылке

- Приглашайте ученика на доску кнопкой «Поделиться»: для входа по ссылке не нужен аккаунт.
- Рисуйте одновременно и сразу видьте штрихи друг друга. Можно вместе стирать, добавлять изображения и сохранять результат в PNG.
- Отключайте общий доступ после занятия: участники покинут доску, а старая ссылка покажет «Доска больше недоступна».
- При повторном включении создаётся новая ссылка — прежняя больше не работает.
- При обрыве связи изменения остаются в локальном черновике и автоматически синхронизируются после подключения. Отмена действия не удаляет рисунки другого участника.

## Новый интерфейс

- Обновлены главная страница, формы входа и рабочее пространство с контрастными бело-голубыми панелями.
- «Войти в аккаунт» теперь заметнее, а «Открыть доску» сразу запускает гостевой режим.
- На главной появилось интерактивное демо рисования.
- Убрано появление неоформленной страницы при загрузке стилей.

Windows-приложение получит обновлённый интерфейс с сайта; переустанавливать оболочку 0.2.0 не требуется. Уже полученные участником рисунки, изображения и скриншоты невозможно удалить с его устройства отзывом ссылки.
