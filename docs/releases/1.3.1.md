# BluviBoard 1.3.1

## Что нового

- В окне «Что нового» доступны изменения последних трёх версий, от новой к старым. Историю можно пролистать и открыть повторно из боковой панели или стартовой страницы.

## Обновления

- Если актуальный интерфейс уже загрузился при открытии сайта или приложения, служебное обновление применяется в фоне без лишней кнопки «Обновить» и перезапуска.
- Обновление служебного компонента больше не показывает описание уже прочитанной версии повторно.
- Для открытого окна с другой сборкой сохранено обновление с предварительным сохранением доски.
