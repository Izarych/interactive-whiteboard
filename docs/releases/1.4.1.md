# BluviBoard 1.4.1

## Работа при сбоях связи

- На уже открытой доске можно продолжать рисовать при временной недоступности сайта или интернета, в том числе в Windows-клиенте.
- Вместо повторяющихся сообщений об ошибке сохранения отображается тихий статус «Сохранено на устройстве»; изменения остаются в локальном черновике.
- После восстановления сервера актуальные изменения автоматически отправляются в фоне, без перезагрузки холста.
- Конфликты с изменениями из другого окна не затирают серверную версию. Если локальная копия недоступна, приложение предупреждает о риске потери данных.

Для запуска приложения с нуля, открытия других досок и загрузки новых изображений по-прежнему требуется доступный сайт. До синхронизации не очищайте данные приложения и не закрывайте окно с несохранёнными изменениями.
