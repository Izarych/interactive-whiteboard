# BluviBoard 1.4.0

## Фигуры

- Единый инструмент «Фигуры» с выбором под панелью: треугольник, квадрат, прямоугольник, круг, овал, прямая линия, стрелка, трапеция и параллелепипед.
- Квадрат и круг сохраняют пропорции без удержания модификатора; у фигур настраиваются цвет и толщина контура.
- Превью во время рисования, сохранение на доске, отмена, повтор, стирание контура и экспорт PNG работают для всех фигур.
- Старые прямоугольники, овалы и назначенные им хоткеи поддерживаются в новом инструменте.
