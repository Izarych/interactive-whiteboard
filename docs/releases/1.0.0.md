# BluviBoard 1.0.0

Первый официальный production-релиз BluviBoard — интерактивной браузерной доски.

## Доски и рисование

- Несколько досок с созданием, переименованием, переключением и удалением.
- Карандаш, цвета, толщина, фигуры, ластик, отмена и повтор действий.
- Масштабирование и перемещение холста.
- Фон «Чистый», «Точки» или «Клетка» с точной настройкой размера.
- Вставка скриншотов через Ctrl+V, загрузка изображений, изменение их размера и положения.
- Автосохранение, локальный черновик и экспорт PNG.

## Аккаунты

- Регистрация с подтверждением почты кодом, вход и гостевой режим.
- Перенос гостевых досок и изображений в аккаунт.
- Редактирование имени и аватара, восстановление пароля.
- PostgreSQL, локальное хранилище изображений и возможность подключения Yandex Object Storage.
- Фирменные HTML-письма; production-почта с SPF/DKIM.

## Администрирование

- Административный вход без регистрации и гостевого режима.
- Дашборд с аналитикой пользователей, гостей, досок и хранилища.
- Управление пользователями, ролями, сессиями, гостями, досками и изображениями.
- Журнал административных действий.
- Создание нового административного аккаунта серверной командой.

## Production

- https://bluviboard.ru с HTTPS и автоматическим продлением сертификата.
- CI со сборкой, аудитом зависимостей, интеграционными и браузерными проверками.
- Автодеплой проверенных коммитов `main` без создания служебных тегов или GitHub Releases.
- Проверка работоспособности после установки, откат при ошибке и ежедневные резервные копии.

Официальные релизы публикуются только по версиям вида `X.Y.Z`.
