# BluviBoard 1.0.0

Первый стабильный релиз BluviBoard.

## Возможности

- Несколько досок с автосохранением, переименованием и удалением.
- Карандаш, палитра, фигуры, ластик, отмена и повтор действий.
- Масштабирование и перемещение холста, клетка и точки с настройкой размера.
- Вставка скриншотов, загрузка и редактирование изображений, экспорт PNG.
- Гостевой режим, регистрация с подтверждением почты и перенос гостевых досок в аккаунт.
- Профиль с именем и аватаром, восстановление пароля.
- Административная панель с аналитикой и управлением пользователями, ролями и досками.
