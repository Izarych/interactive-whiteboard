# BluviBoard 1.2.0

## Добавлено

- Настраиваемые хоткеи для выбора инструментов: отдельная клавиша или сочетание, например CapsLock или Ctrl+F1.
- Назначение хоткея нажатием нужных кнопок прямо из панели инструментов: через значок клавиатуры или правую кнопку на инструменте.
- Повторное нажатие хоткея возвращает инструмент, выбранный до переключения.
- Настройки сохраняются в аккаунте для всех досок и доступны после повторного входа, в том числе с другого устройства. В гостевом режиме они сохраняются в гостевом пространстве.

По умолчанию хоткеи инструментов не назначены. Во время ввода текста инструменты по хоткеям не переключаются.
