# BluviBoard 1.3.3

## Настройки инструментов

- Флажок закрепления настроек перенесён в левую часть панели инструментов. Выбор по-прежнему сохраняется для всех досок пользователя.
- Из выпадающих настроек убраны поясняющие подписи и отдельная кнопка назначения хоткея; хоткей доступен через значок клавиатуры и правую кнопку на инструменте.
- Панели настроек стали компактнее: в них остались цвет, толщина, непрозрачность маркера, параметры ластика и основные действия текущего инструмента.
