# BluviBoard 1.7.0

## Приложение для Windows и Mac

- Автономный редактор теперь доступен для macOS 14 и новее: отдельные `.dmg` для Mac с Apple Silicon и Intel.
- Рисование, изображения, локальные доски, файлы `.bluviboard` и экспорт PNG работают без интернета.
- При входе доступна синхронизация с аккаунтом. На Mac сессия сохраняется в системной Связке ключей.
- Добавлены привычные команды меню Mac и безопасное закрытие через Cmd+Q.
- Проверка обновлений выбирает установщик для операционной системы и процессора.

## Установщики в релизе

В разделе **Assets** основного релиза доступны установщики Windows и Mac вместе с контрольными суммами. На сайте есть ссылки для всех трёх вариантов.

Windows: `BluviBoard-Setup-0.4.0-x64.exe`. Mac: `BluviBoard-0.4.0-macOS-arm64.dmg` (Apple Silicon) или `BluviBoard-0.4.0-macOS-x64.dmg` (Intel).

Установщики пока не имеют подписи издателя; macOS-сборки не нотариализованы Apple. При первом открытии система может показать предупреждение безопасности. Общий доступ и живое совместное рисование по-прежнему доступны на сайте; оффлайн-правки совместной доски сохраняются отдельной копией.
